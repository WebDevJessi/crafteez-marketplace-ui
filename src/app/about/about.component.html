01 / the story

A place for
the creatives.

Hi! Thank you for visiting Crafteez. This is a small project I started based on the inspiration of my own love of crafts. My name is Jess, I am a Software Engineer of 4 years, and this is my first full-scale project using my knowledge and skills from my career. I wanted to create an e-commerce site that is simple, easy to use, and most of all, something that I would want to use myself.

I wanted to create a front end with Angular using RxJs and Angular Material, a back end with Node.js and Express, and a database using MySQL. I chose to use all of these with the idea in mind that Crafteez could one day turn in to an enterprise level application (if it were real, that is). Coming from an enterprise background myself, I tend to veer towards this way of thinking, knowing full well that this could have been a much more small scale project using a simpler stack. I really wanted to challenge myself to understand more about these technologies and how they work together, and I feel like I have learned a lot from this project. Disclaimer: None of these products are for sale and this is not a real site. This is a personal project and is not affiliated with any real company or organization.

How Crafteez
was made.

01

Front End

The front end of Crafteez was built with Angular TypeScript, utilizing RxJs for reactive programming and Angular Material for a modern UI. I am still getting the hang of UI design so I relied on Angular Material and AI to help me build some of the sections to get a more visually tasteful design. The rest of the features such as the slideshow were ways I wanted to challenge myself to incorporate additional 3rd party elements to play around with. The UI code can be found here: CrafteezMarketplaceUi

02

Back End

The back end of Crafteez was built with Node.js TypeScript, Express, and Prisma, providing a robust API for handling requests and managing data. The back end code can be found here:
crafteez-marketplace-node

03

Database

The database of Crafteez was built with MySQL, providing a reliable storage solution for managing product information and potentially user data. In truth, a database was really not necessary for this small project. But if someone asked me to create a website that would be enterprise level, I would think a database is necessary for keeping track of users, orders, product quantities/information, and keep things unified.
